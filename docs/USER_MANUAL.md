## 一、快速开始（首次使用）

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 安装 APK 并打开 | 系统会请求「照片和视频」权限 |
| 2 | 选择「始终允许所有照片」 | Android 14+ 必须选这一项，否则相册为空 |
| 3 | 可选：允许「照片中的位置信息」 | 用于读取 GPS 地点；拒绝不影响时间检索与内容搜索 |
| 4 | 可选：允许通知权限 | 用于显示分析进度；拒绝不影响功能 |
| 5 | 点首页「开始分析」 | 分析完成后才能按内容搜索 |
| 6 | 可选：配置云端 AI | 设置 → 启用云端 AI 分析 → 选服务 → 填 API Key → 保存 |

**没有 API Key 也能用**：仅使用本地 ML Kit 标签，内容检索仍可用，但描述性查询（如「光膀子的男人」）效果会弱一些。智谱 AI 的 `glm-4v-flash` 模型免费，适合日常使用。

## 二、照片分析与断点续跑

这是 v3.9.0 重点修复的场景：**照片很多时分析经常中断，以前每次都要从头再来**。

### 现在的行为

- 分析在后台服务运行，通知栏显示「已完成 X / 总 Y，还剩 Z 张」。
- **每张照片分析完立即单独保存**。可以随时退出应用、锁屏、切换任务，不会丢失进度。
- 若被系统终止、关机或应用被划掉，下次**只分析没跑过的照片**，绝不从头开始。
- 回到应用时默认**自动接着上次继续**（设置 → 分析进度 →「自动继续未完成的照片分析」，可关闭）。关闭后首页会显示「继续」按钮。
- 首页状态条显示「已分析 X 张，还有 Y 张待分析」。进度口径是相册里已完整分析的照片，不是本轮处理序号。

### 照片变化时的处理

| 情况 | 行为 |
| --- | --- |
| 新拍了照片 / 刚下载图片 | 只增量分析新增的照片，已分析过的不重跑 |
| 删除了几张照片 | 其他照片的结果不受影响 |
| 相册排序变化 | 按照片 ID 匹配，不会产生错位或重复分析 |
| 云端 AI 限流 / 断网导致部分照片只有本地标签 | 下次开启 AI 时自动补齐这些照片的中文描述，无需「重新分析全部」 |
| 分析完成后又新增照片 | 自动只分析新增的那几张 |

### 相关设置

| 设置项 | 位置 | 作用 |
| --- | --- | --- |
| 自动继续未完成的照片分析 | 设置 → 分析进度 | 默认开启；关闭后需在首页点「继续」 |
| 进度标记刷新间隔 | 设置 → 存储设置 | 只控制进度数字多久写一次磁盘，**不影响安全性**，结果本身每张都立即保存 |
| 启用云端 AI 分析 / 服务 / API Key | 设置 → AI 分析设置 | 影响是否生成中文描述 |

### 主动重来的方式

| 需求 | 入口 |
| --- | --- |
| 彻底重来（会清空全部结果，请谨慎） | 右上角更多菜单 →「重新分析全部」 |
| 只重跑少数照片 | 更多菜单 →「多选照片重新分析」，长按或点选后点「重新分析」 |
| 只刷新一张 | 照片详情页 →「重新分析这张」 |

> 连续失败 20 次时，云端 AI 会在本轮自动降级为本地分析并在通知里提示，下次进入应用再自动补齐，不会卡死也不会反复重试。

## 三、搜索照片内容

点顶栏放大镜图标展开搜索框，输入后即时显示；检索在后台执行，连续快速输入不会卡顿或丢字。

| 类型 | 示例 |
| --- | --- |
| 直接写内容词 | `汽车`、`有猫的照片`、`海边日落`、`两个人吃饭`、`发票`、`自行车` |
| 中文描述 | `光膀子的男人`、`红色轿车的照片` |
| 英文原词 | `car`（分析出的标签在界面上统一显示为中文，但英文查询仍可命中） |
| 排除条件 | `没有汽车的风景`、`不含建筑物`（排除词不会被当成命中词反向加分） |
| 多条件 | `猫 或 狗`、`北京 汽车` |

搜索框下方提供建议词，点一下即可填入。顶部摘要栏显示当前条件与结果数，点「调整」修改，点 × 清除全部条件。

## 四、按时间检索

时间可以写在搜索框里，也可以在「时间与地点筛选」面板设定，两种方式可叠加。

| 写法 | 示例 |
| --- | --- |
| 年份 | `2023年` |
| 年月 | `2023年6月`（自动扩展为整月） |
| 标准日期 | `2023-06-01`、`2023/6/1`、`2023.6.1`、`20230601` |
| 日期区间 | `2023-01-01 到 2023-06-30`、`2023年6月1日 至 2023年12月31日`（起止均闭区间） |
| 相对时间 | `最近三个月`、`最近一年`、`去年`、`去年夏天`、`今年春天`、`国庆`、`春节` |

筛选面板提供「最近 7 天 / 30 天 / 今年 / 去年」等快捷按钮，也支持自定义开始、结束日期。提示格式统一为 `2023年6月1日 至 2023年12月31日`。若照片没有拍摄时间，面板会提示「N 张无时间信息」。

## 五、按地点检索与时间地点联动

- 搜索框直接写城市名：`北京`、`上海`、`杭州`、`无锡`，支持别名、拼音与模糊写法（如「帝都」「魔都」）。
- 筛选面板列出**当前时间区间内**出现过的地点候选及照片数量，点一下即可选中。候选会随时间区间变化重新统计，这就是「时间地点联动」。
- 也可以手动输入地点并点「使用此地点」，支持不精确的名称；系统按城市坐标半径与文本模糊两种方式匹配。
- 组合查询示例：

| 查询 | 生效条件 |
| --- | --- |
| `2023年 北京 汽车` | 时间 AND 地点 AND 内容 |
| `最近三个月 上海 咖啡` | 同上 |
| `去年夏天 海边 日落` | 同上 |

- 没有 GPS 的照片：在详情页「地点」处手动标注一个地点，之后即可参与地点检索。
- 若某张照片缺少时间或地点信息，筛选面板会分别提示数量；放宽条件或清除筛选可让它们重新出现。

## 六、浏览照片：网格与列表

顶栏第三个图标在「缩略图网格」与「信息列表」之间切换，偏好会被记住。

| 视图 | 展示内容 |
| --- | --- |
| 缩略图网格 | 纯缩略图，适合快速浏览 |
| 信息列表 | 拍摄时间、地点、文件格式、分辨率、文件大小、相机、中文内容标签 |

列表中的时间地点来自 EXIF / MediaStore，缺失时显示「未知」；手动标注的地点会带标记。长按任意照片进入多选模式，可全选后批量重新分析；点顶栏 × 退出多选。

## 七、照片详情与 EXIF 信息

点照片进入详情页，可查看：

- AI 中文描述、内容标签、识别物体、关键词（全部中文，按置信度去重）
- 拍摄时间、地点、地点来源（系统逆地理编码 / GPS 城市匹配 / 手动标注）
- **拍摄参数与文件信息**：相机厂商与型号、镜头、软件、作者、光圈、快门、ISO、焦距、等效焦距、曝光补偿、闪光灯、白平衡、方向、像素宽高、GPS 海拔与日期戳、MIME / 大小 / 扩展名
- **可检索标签**：由上述参数生成的中文标签，如 `佳能`、`竖幅`、`广角`、`大光圈`、`JPEG`、`春季`、`周末`，可直接当搜索词使用

详情页还可「分享」照片、「重新分析这张」、手动标注地点。

**返回上一级**：从屏幕左边缘向右滑，或按系统返回键。详情页、设置页、版本说明、操作手册都支持。

## 八、常见问题与降级处理

| 问题 | 处理 |
| --- | --- |
| 看不到相册照片 | 确认已授予「照片和视频」权限；更多菜单 →「重新加载相册」；Android 14 选「始终允许所有照片」；仍为空则重启应用 |
| 搜索不到想要的结果 | 确认照片已分析完成；换更具体的名词（`轿车` 比 `车` 准）；开启云端 AI 描述；检查是否叠加了时间/地点筛选，点「清除全部条件」再试 |
| 分析中断 / 每次从头 | v3.9.0 已按照片 ID 断点续跑。旧版本请升级；升级后点一次「继续」即可，已分析的照片不会重跑 |
| 云端 AI 报错或很慢 | 检查服务与 API Key、网络；连续失败 20 次本轮自动降级为本地分析，下次进入应用自动补齐 |
| 照片很多（几万张）时卡顿 | v3.8.0 起检索已后台异步化并带缓存，输入与滚动不受影响；首次分析仍需时间，建议分批或在网络良好时开启 AI |
| 换版本安装 | 所有发行版使用同一签名，直接覆盖安装即可保留分析结果；若提示签名冲突，先卸载再安装（会清空分析缓存） |
| 清缓存 / 重置 | 更多菜单 →「重新分析全部」清空 AI 结果与进度；卸载应用会清除全部私有数据 |

## 九、数据与隐私说明

- 照片本身不会被上传；只有开启云端 AI 分析时，才会把所选照片发送给设置中指定的模型服务生成描述。
- 分析结果、EXIF 信息、手动标注地点与设置都保存在应用私有目录（`filesDir`），不上传、不共享。
- 关闭云端 AI 后，全部识别都在设备本地完成（ML Kit），可完全离线使用。
- 分析进度按行式文件逐张追加，意外断电或强杀最多丢失当前正在处理的那一张。
