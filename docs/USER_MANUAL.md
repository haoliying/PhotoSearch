## 一、快速开始（首次使用）

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 安装 APK 并打开 | 系统会请求「照片和视频」权限 |
| 2 | 选择「始终允许所有照片」 | Android 14+ 必须选这一项，否则相册为空 |
| 3 | 可选：允许「照片中的位置信息」 | 用于读取 GPS 地点；拒绝不影响时间检索与内容搜索 |
| 4 | 可选：允许通知权限 | 用于显示分析进度；拒绝不影响功能 |
| 5 | 点首页「开始分析」 | 分析完成后才能按内容搜索 |
| 6 | 可选：配置大模型 | 设置 →「大模型使用方式」选策略 →（非「不使用」时）选服务、填 API Key → 保存 |

**没有 API Key 也能用，而且 v3.11.0 起明显更准**：关掉大模型后全部走端侧识别，本地准确度增强会把主色、明暗、横竖幅、人数、文字、多场景、低置信标签都变成可检索的中文标签，并自动扩展同义词（搜「汽车」能命中标签为「车辆 / vehicle」的照片）。复杂描述性查询（如「光膀子的男人」）仍建议配置云端 AI。智谱 AI 的 `glm-4v-flash` 模型免费，适合日常使用。

## 二、照片分析与断点续跑

这是 v3.9.0 重点修复的场景：**照片很多时分析经常中断，以前每次都要从头再来**。

### 现在的行为

- 分析在后台服务运行，通知栏显示「已完成 X / 总 Y，还剩 Z 张」。
- **每张照片分析完立即单独保存**。可以随时退出应用、锁屏、切换任务，不会丢失进度。
- 若被系统终止、关机或应用被划掉，下次**只分析没跑过的照片**，绝不从头开始。
- 回到应用时默认**自动接着上次继续**（设置 → 分析进度 →「自动继续未完成的照片分析」，可关闭）。关闭后首页会显示「继续」按钮。
- 首页状态条显示「已分析 X 张，还有 Y 张待分析」。进度口径是相册里已完整分析的照片，不是本轮处理序号。

### 照片变化时的处理

| 情况 | 行为 |
| --- | --- |
| 新拍了照片 / 刚下载图片 | 只增量分析新增的照片，已分析过的不重跑 |
| 删除了几张照片 | 其他照片的结果不受影响 |
| 相册排序变化 | 按照片 ID 匹配，不会产生错位或重复分析 |
| 云端 AI 限流 / 断网导致部分照片只有本地标签 | 下次开启 AI 时自动补齐这些照片的中文描述，无需「重新分析全部」 |
| 分析完成后又新增照片 | 自动只分析新增的那几张 |

### 相关设置

| 设置项 | 位置 | 作用 |
| --- | --- | --- |
| 自动继续未完成的照片分析 | 设置 → 分析进度 | 默认开启；关闭后需在首页点「继续」 |
| 进度标记刷新间隔 | 设置 → 存储设置 | 只控制进度数字多久写一次磁盘，**不影响安全性**，结果本身每张都立即保存 |
| 启用云端 AI 分析 / 服务 / API Key | 设置 → AI 分析设置 | 影响是否生成中文描述 |
| 分析速度（端侧识别） | 设置 → 分析速度 | v3.11.2：1 / 2 / 4 / 8 路滑动窗口并发，默认 4 路。越高全量分析越快，1 路等价旧版逐张串行（最省电）；与是否使用大模型无关，两条通道都提速 |
| 暂停 / 继续分析 | 首页分析状态条、守护行、通知栏 | v3.11.2 新增：临时停止分析，守护仍常驻；继续时按已分析结果从剩余照片续跑，不会从头开始。暂停状态会被记住，重启手机也不偷偷恢复 |
| 打开电池优化设置 | 设置 → 分析速度卡片内 | 部分国产 ROM 会额外限制后台运行，需手动把应用设为「不受电池优化限制 / 允许后台运行」 |

> **v3.11.2 提速与后台说明**：v3.11.1 是「整块并行、整块收尾」，一块里最慢的照片会拖住同块其他线程；
> 现在改为固定 N 张同时分析、谁完成立刻补下一张（滑动窗口），并放到低优先级专用线程池，
> 解码边长也从 1024 降到 768。分析期间持有 CPU 唤醒锁，熄屏后不会被系统冻结；
> 空闲时每 60 秒做一次轻量对账，新照片即使没触发相册监听也会被捡起来分析。
> 已有断点续跑、增量事件、「后台分析不影响前端搜索」的隔离全部保持不变。

### 主动重来的方式

| 需求 | 入口 |
| --- | --- |
| 彻底重来（会清空全部结果，请谨慎） | 右上角更多菜单 →「重新分析全部」 |
| 只重跑少数照片 | 更多菜单 →「多选照片重新分析」，长按或点选后点「重新分析」 |
| 只刷新一张 | 照片详情页 →「重新分析这张」 |

> 连续失败 20 次时，云端 AI 会在本轮自动降级为本地分析并在通知里提示，下次进入应用再自动补齐，不会卡死也不会反复重试。

### 后台自动分析与相册监听（v3.10.0）

v3.10.0 起分析默认**在后台常驻运行**，不再需要每次手动点「开始分析」：

| 行为 | 说明 |
| --- | --- |
| 常驻 | 退出应用、锁屏、切到别的应用都不会停；被系统回收后自动重启并接着跑 |
| 监听相册 | 新拍的照片、刚下载或保存的图片会被自动发现 |
| 自动分析 | 只分析新增的照片，结果逐张保存；已分析过的绝不重跑 |
| 立即显示 | 新照片马上出现在相册里，AI 描述与中文标签随后自动补齐 |
| 不影响搜索 | 后台分析跑在低优先级线程、结果按批增量更新，只刷新新增照片的索引，不清空缓存、不全库重算 |

**开关与状态**

- 设置 →「后台运行 → 后台自动分析」（默认开）可随时关闭；右上角更多菜单、通知栏「停止守护」也可停。
- 首页在分析完成且守护运行时会显示极轻一行「后台守护中 · 新增照片会自动分析（不影响搜索）」，点「停止」可关闭。
- 通知栏有一条低优先级「后台守护」通知，点「停止守护」即可关闭。

**关闭后会怎样**：服务退化为一次性分析，跑完即退出，回到「手动开始 / 回到前台自动续跑」模式（v3.9.0 行为）。

**系统限制**：少数系统（尤其有严格省电策略的机型）会限制开机后自动启动后台服务，此时打开一次应用即恢复守护；建议把应用加入电池优化白名单。云端 AI 开启时后台自动分析新照片会消耗流量，可按需关闭。

## 三、搜索照片内容

点顶栏放大镜图标展开搜索框，输入后即时显示；检索在后台执行，连续快速输入不会卡顿或丢字。

| 类型 | 示例 |
| --- | --- |
| 直接写内容词 | `汽车`、`有猫的照片`、`海边日落`、`两个人吃饭`、`发票`、`自行车` |
| 中文描述 | `光膀子的男人`、`红色轿车的照片` |
| 英文原词 | `car`（分析出的标签在界面上统一显示为中文，但英文查询仍可命中） |
| 排除条件 | `没有汽车的风景`、`不含建筑物`（排除词不会被当成命中词反向加分） |
| 多条件 | `猫 或 狗`、`北京 汽车` |

搜索框下方提供建议词，点一下即可填入。顶部摘要栏显示当前条件与结果数，点「调整」修改，点 × 清除全部条件。

## 四、按时间检索

时间可以写在搜索框里，也可以在「时间与地点筛选」面板设定，两种方式可叠加。

| 写法 | 示例 |
| --- | --- |
| 年份 | `2023年` |
| 年月 | `2023年6月`（自动扩展为整月） |
| 标准日期 | `2023-06-01`、`2023/6/1`、`2023.6.1`、`20230601` |
| 日期区间 | `2023-01-01 到 2023-06-30`、`2023年6月1日 至 2023年12月31日`（起止均闭区间） |
| 相对时间 | `最近三个月`、`最近一年`、`去年`、`去年夏天`、`今年春天`、`国庆`、`春节` |

筛选面板提供「最近 7 天 / 30 天 / 今年 / 去年」等快捷按钮，也支持自定义开始、结束日期。提示格式统一为 `2023年6月1日 至 2023年12月31日`。若照片没有拍摄时间，面板会提示「N 张无时间信息」。

## 五、按地点检索与时间地点联动

- 搜索框直接写城市名：`北京`、`上海`、`杭州`、`无锡`，支持别名、拼音与模糊写法（如「帝都」「魔都」）。
- 筛选面板列出**当前时间区间内**出现过的地点候选及照片数量，点一下即可选中。候选会随时间区间变化重新统计，这就是「时间地点联动」。
- 也可以手动输入地点并点「使用此地点」，支持不精确的名称；系统按城市坐标半径与文本模糊两种方式匹配。
- 组合查询示例：

| 查询 | 生效条件 |
| --- | --- |
| `2023年 北京 汽车` | 时间 AND 地点 AND 内容 |
| `最近三个月 上海 咖啡` | 同上 |
| `去年夏天 海边 日落` | 同上 |

- 没有 GPS 的照片：在详情页「地点」处手动标注一个地点，之后即可参与地点检索。
- 若某张照片缺少时间或地点信息，筛选面板会分别提示数量；放宽条件或清除筛选可让它们重新出现。

## 六、浏览照片：网格与列表

顶栏第三个图标在「缩略图网格」与「信息列表」之间切换，偏好会被记住。

| 视图 | 展示内容 |
| --- | --- |
| 缩略图网格 | 纯缩略图，适合快速浏览 |
| 信息列表 | 拍摄时间、地点、文件格式、分辨率、文件大小、相机、中文内容标签 |

列表中的时间地点来自 EXIF / MediaStore，缺失时显示「未知」；手动标注的地点会带标记。长按任意照片进入多选模式，可全选后批量重新分析；点顶栏 × 退出多选。

## 七、照片详情与 EXIF 信息

点照片进入详情页，可查看：

- AI 中文描述、内容标签、识别物体、关键词（全部中文，按置信度去重）
- 拍摄时间、地点、地点来源（系统逆地理编码 / GPS 城市匹配 / 手动标注）
- **拍摄参数与文件信息**：相机厂商与型号、镜头、软件、作者、光圈、快门、ISO、焦距、等效焦距、曝光补偿、闪光灯、白平衡、方向、像素宽高、GPS 海拔与日期戳、MIME / 大小 / 扩展名
- **可检索标签**：由上述参数生成的中文标签，如 `佳能`、`竖幅`、`广角`、`大光圈`、`JPEG`、`春季`、`周末`，可直接当搜索词使用

详情页还可「分享」照片、「重新分析这张」、手动标注地点。

**返回上一级**：从屏幕左边缘向右滑，或按系统返回键。详情页、设置页、版本说明、操作手册都支持。

## 八、常见问题与降级处理

| 问题 | 处理 |
| --- | --- |
| 看不到相册照片 | 确认已授予「照片和视频」权限；更多菜单 →「重新加载相册」；Android 14 选「始终允许所有照片」；仍为空则重启应用 |
| 搜索不到想要的结果 | 确认照片已分析完成；换更具体的名词（`轿车` 比 `车` 准）；确认设置页「启用本地准确度增强」为开启；也可在「大模型使用方式」里选「仅识别不确定的照片」让 AI 补短板；检查是否叠加了时间/地点筛选，点「清除全部条件」再试 |
| 不想让照片联网 / 想省流量 | 设置 →「大模型使用方式」选「不使用大模型」；或选「仅手动选择的照片」只精修少数几张；配合「仅 Wi-Fi 下使用大模型」 |
| 分析中断 / 每次从头 | v3.9.0 已按照片 ID 断点续跑。旧版本请升级；升级后点一次「继续」即可，已分析的照片不会重跑 |
| 云端 AI 报错或很慢 | 检查服务与 API Key、网络；连续失败 20 次本轮自动降级为本地分析，下次进入应用自动补齐 |
| 照片很多（几万张）时卡顿 | v3.8.0 起检索已后台异步化并带缓存，输入与滚动不受影响；首次分析仍需时间，建议分批或在网络良好时开启 AI |
| 不用大模型时分析仍慢 | v3.11.2 起默认 4 路滑动窗口并发（可调到 8 路），并优化了解码尺寸；先确认没把并发误设成 1 路。发烫就退回 1 路 |
| 退到后台就不分析了 / 进度很久不动 | v3.11.2 起分析时持有 CPU 唤醒锁，熄屏不再被冻结，并有 60 秒低频心跳对账；通知栏会实时显示「正在分析 x / y」。国产 ROM 需到「设置 → 打开电池优化设置」允许后台运行 |
| 进度数字一次跳几百 | v3.11.2 已把进度改为服务侧逐张累加的单一数据源，数值只增不减、200ms 刷新；若仍看到旧行为请确认已升级 |
| 想临时停止分析 | 首页状态条点「暂停分析」或下拉通知栏点「暂停分析」；恢复点「继续分析」，按已分析结果从剩余照片续跑，不会从头开始 |
| 换版本安装 | 所有发行版使用同一签名，直接覆盖安装即可保留分析结果；若提示签名冲突，先卸载再安装（会清空分析缓存） |
| 清缓存 / 重置 | 更多菜单 →「重新分析全部」清空 AI 结果与进度；卸载应用会清除全部私有数据 |

## 九、数据与隐私说明

- 照片本身不会被上传；只有开启云端 AI 分析时，才会把所选照片发送给设置中指定的模型服务生成描述。
- 分析结果、EXIF 信息、手动标注地点与设置都保存在应用私有目录（`filesDir`），不上传、不共享。
- 关闭云端 AI 后，全部识别都在设备本地完成（ML Kit），可完全离线使用。
- 分析进度按行式文件逐张追加，意外断电或强杀最多丢失当前正在处理的那一张。

## 十、大模型使用策略与本地准确度增强（v3.11.0）

### 10.1 选择用不用、给谁用

设置 →「大模型使用方式」，共 5 种策略：

| 策略 | 什么时候用 |
| --- | --- |
| 不使用大模型 | 完全不想联网、没有 API Key、或对隐私要求最高。此时 100% 端侧识别 |
| 全部照片 | 追求最高准确度，不在意流量与耗时 |
| 仅新增 / 未分析的照片 | 存量照片已有描述，只处理新拍、新下载的照片 |
| 仅识别不确定的照片（推荐） | 端侧识别标签少、置信度低、场景不明确的照片才交给 AI 精修，最省流量 |
| 仅手动选择的照片 | 只想精修自己挑的少数几张 |

- 选「仅识别不确定的照片」时可调整 **识别可信度阈值**（0~100%，默认 55%）：数值越大，交给大模型的照片越多。
- **仅 Wi-Fi 下使用大模型**：移动数据下自动跳过云端分析，连上 Wi-Fi 后由后台守护补上。
- 非「不使用」策略下才能配置 AI 服务与 API Key。
- 旧版「启用云端 AI 分析」开关会自动迁移：原本关闭的继续是「不使用」，其余默认「全部」。

### 10.2 只让指定的照片用大模型

1. 首页右上角更多菜单 →「多选照片（重新分析 / 交给大模型）」；
2. 勾选照片（可点右上角「全选」选中当前结果）；
3. 底部有两个按钮：
   - **重新分析**：只跑端侧识别，不联网；
   - **用大模型分析**：把这些照片明确交给云端大模型精修。
4. 勾选后无论当前是哪种策略（除「不使用」），这些照片都会被强制加入队列，分析完自动从待办里移除，不会反复重跑。

> 若当前是「不使用大模型」或没填 API Key，点「用大模型分析」会提示先去设置里改配置。

### 10.3 不用大模型时，准确度靠什么提升

v3.11.0 的「本地准确度增强」**不换模型、不联网、不需要重跑分析**，只是把端侧已经算出、过去被浪费的信息补进检索索引：

| 能力 | 现在能搜到什么 |
| --- | --- |
| 颜色 / 明暗 | 蓝天、绿植、暖色调、夜景、黑白、鲜艳、明亮 |
| 构图 | 竖幅、横幅、方形、全景、长图、手机截图 |
| 人数 | 单人、双人、合影、多人、人群、自拍 |
| 文字 | 文字、文档、截图（竖长图含文字） |
| 多场景 | 一张「夜晚 + 城市 + 车」同时具备三个场景标签 |
| 低置信标签 | 远景小车、遮挡宠物等原本被丢弃的 0.15~0.30 标签 |
| 查询同义扩展 | 搜「汽车」能命中「车辆 / 轿车 / vehicle / car」，搜「合影」能命中「合照 / 一群人」 |
| 多弱证据叠加 | 多条互相印证的弱线索可以顶替一条强线索 |

**升级即生效**：这些标签是从已落盘的结构化字段实时推导的，历史分析结果无需重新分析。想对比效果，可在设置页关掉「启用本地准确度增强」并保存，检索行为会回到 v3.10.0。

详细原理、取舍与评测数据见仓库文档 `docs/ACCURACY_WITHOUT_VLM.md`（应用内「操作手册」也有本节摘要）。

### 10.4 推荐组合

| 你的情况 | 建议 |
| --- | --- |
| 完全离线 / 无 API Key | 「不使用大模型」+ 本地增强开启 |
| 想省流量但尽量准 | 「仅识别不确定的照片」阈值 55% + 「仅 Wi-Fi」 |
| 只精修少数照片 | 「仅手动选择的照片」+ 相册多选 →「用大模型分析」 |
| 存量已有描述，只管新照片 | 「仅新增 / 未分析的照片」 |

## 十一、分析速度、后台持续分析与暂停 / 继续（v3.11.2）

### 1. 分析速度怎么调

| 档位 | 适用 |
| --- | --- |
| 1 路 | 最省电，等价旧版逐张串行；手机发烫或前台有明显感知时用 |
| 2 路 | 温和提速 |
| **4 路（默认）** | 日常推荐，能吃满中端机 CPU |
| 8 路 | 首次全量几万张照片时追求最快，可能发热 |

位置：**设置 → 分析速度（端侧识别）**。只影响之后开始的分析，既有结果不受影响；与「是否使用大模型」无关，两条通道都提速。批量多选 →「重新分析」同样按该档位并发。

**为什么 v3.11.1 调了并发仍慢**：那一版是「整块并行、整块收尾」，一块里最慢的照片会拖住同块其他线程（木桶效应）。v3.11.2 改为滑动窗口 —— 固定 N 张同时分析，**任何一张完成立刻补下一张**，全程保持 N 张在跑。离线调度模型上，同样 4 路从 4335 ms 降到 1705 ms（提速 60%），8 路 1500 ms。分析跑在低优先级专用线程池，与搜索线程隔离，所以全速分析时输入搜索框仍不卡。

### 2. 后台为什么之前会「停」

Android 熄屏后会允许 CPU 休眠，**前台服务虽然不被杀，计算却被冻结**，表现出来就是进度不动。v3.11.2：

- 分析期间持有 `PARTIAL_WAKE_LOCK`（单次最长 30 分钟，跑完 / 暂停 / 空闲立即释放），熄屏继续算；
- 服务跑完一轮后**不退出**，进入 60 秒低频心跳，只查相册 id 差集（不读分析结果文件），发现新照片立刻续跑 —— 即使系统丢了相册变化回调也不会漏；
- 通知栏实时显示「正在分析 x / y」和暂停 / 继续动作，不用打开 App 就能确认后台在跑；
- 部分手机（尤其国产 ROM）还有额外后台限制，请到 **设置 → 打开电池优化设置**，把本应用设为「不受电池优化限制 / 允许后台运行」。

### 3. 进度条口径

显示的是**相册里已完整分析的张数**，由服务侧每张完成 +1 发布，前端不再自己全库统计（这是旧版数字跳变的根因）。数值只增不减，200 ms 刷新一次，收尾必发最终值 —— 所以不会再一次跳几百，也不会跑完瞬间跳到 100% 再回退。

### 4. 暂停 / 继续分析

| 操作 | 入口 |
| --- | --- |
| 暂停 | 首页分析状态条「暂停分析」、后台守护行「暂停」、通知栏「暂停分析」 |
| 继续 | 首页暂停状态条「继续分析」、通知栏「继续分析」 |

- 暂停时守护**仍常驻**（相册监听、通知都在），只是不再处理照片；当前正在分析的照片会先落盘再挂起，已分析结果不丢；
- 暂停状态写入设置，**服务被系统回收重建后仍保持暂停**，开机或心跳都不会偷偷恢复；
- 继续时立刻唤醒心跳重新对账，按照片 ID 差集只处理剩余部分，**不重复、不从头开始**；若守护已被关掉会自动重新拉起；
- 暂停期间释放唤醒锁，不白耗电。
